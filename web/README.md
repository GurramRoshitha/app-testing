# Voyage AI Planner - Web Version

This is a pixel-perfect web recreation of the Voyage AI Android application. It matches the original design, features, and AI itinerary logic.

## 🚀 Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## 🛠️ Technology Stack

*   **Framework:** React 18
*   **Styling:** Tailwind CSS (Pixel-perfect recreation of Compose UI)
*   **Build Tool:** Vite
*   **Backend:** Firebase (Auth & Firestore)
*   **Icons:** Lucide-React
*   **Animations:** Framer Motion
*   **Utilities:** axios, date-fns

## 📱 Features

*   **AI Journey Generation:** Ported the complete state/district knowledge base for identical itinerary generation.
*   **Dynamic Itinerary:** Interactive daily schedule with category-based styling and timeline UI.
*   **Weather Service:** Real-time weather and 7-day forecasts using Open-Meteo.
*   **Firebase Integration:** Full data synchronization with the Android app's database.
*   **Responsive Design:** Fully optimized for desktop, tablet, and mobile browsers.
*   **Dark Mode:** Integrated theme switching that mirrors Android system settings.
